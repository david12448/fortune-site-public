# Fortune project rules

- Target paths are domain-independent. `SITE_URL` and `BASE_PATH` are configurable; do not connect DNS or set CNAME without approval.
- Public service: dream reference, traditional saju/tojeong interpretation, historical lotto statistics. Clearly distinguish research evidence, tradition, and probability.
- Lunar calendar conversion must handle leap months, solar terms, timezone and unknown birth time. Do not retain birth information by default.
- Fair lotto combinations have equal draw probability; historical frequency is descriptive, not predictive. Do not promote purchase or promise wins.
- Stable lowercase hyphenated slugs; published slugs persist and aliases preserve old links. Direct refresh must return real HTML, not JS-only URL rewriting.
- Public SEO pages must contain unique substantive information. Private computed personal results should be noindex.
- Public pages must not include private source URLs, collection logic, internal datasets, secrets or source maps.
- Do not create recurring ChatGPT progress notifications. Validate before PR merge.
- This repository is public presentation and publishable normalized data only.
